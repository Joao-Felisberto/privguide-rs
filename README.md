# Privguide-RS

A port of [privguide](https://github.com/ATNoG/rigourous-devprivops) to rust.

Why? Corporate development is no fun.

## Scope

This project aims to build upon my previous work to make it more usable, easier to distribute, and fun to maintain.

> [!WARNING]
> This project is being developed in my free time, it will be slow to update and respond to issues.
> It is also not yet production ready, nor am I aiming to make it production ready for now.
> I welcome any contribution and interest, but be aware that this is not a priority for me.
